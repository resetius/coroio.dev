Detailed Description

template<typename T>
class NNet::NDetail::TIntrusiveList< T >

Doubly linked list of objects derived from TIntrusiveNode.

The list does not own its objects: it only links them, without allocating. It is circular around a sentinel node, so linking and unlinking do not branch. The sentinel points to itself, so the list can be neither copied nor moved. Objects must be unlinked before they are destroyed.

struct TItem: NDetail::TIntrusiveNode<TItem> { int Value = 0; };
NDetail::TIntrusiveList<TItem> list;
TItem a, b;
list.PushBack(a);
list.PushFront(b);
for (auto& item : list) { ... } // b, a
list.Erase(a);
