Detailed Description

template<typename T>
class NNet::TMpscQueue< T >

Unbounded lock-free queue with many producers and one consumer.

Carries items between threads without allocating: the link is a part of the item (TMpscQueueNode). Push may be called from any thread, Pop from one thread at a time. Items of one producer are popped in the order it pushed them.

Producers push onto a shared lock-free stack (R. K. Treiber, "Systems Programming: Coping with Parallelism", IBM Research Report RJ 5118, 1986). The consumer never pops one item from it: it takes the whole stack with one exchange and reverses it, so there is no ABA problem and an item is never touched by a producer after Push.

The queue does not wake the consumer by itself. Push returns true when the shared stack was empty, and only then may the consumer be asleep. With an INotifier of the consumer's poller:

// Any producer thread
if (queue.Push(std::move(item))) {
notifier.Notify();
}
// Consumer coroutine on the notifier's poller
while (true) {
co_await notifier.Wait();
while (auto item = queue.Pop()) {
Process(*item);
}
}

The consumer must pop until Pop returns nullptr before it waits again: a push onto a non-empty stack does not notify. Between two pops it may suspend on anything else, and under a steady load it should yield to its loop from time to time.
