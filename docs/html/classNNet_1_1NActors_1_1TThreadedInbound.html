Detailed Description

template<typename TPoller, typename TDelivery, typename TEnvelopeReader = TZeroCopyEnvelopeReader>
class NNet::NActors::TThreadedInbound< TPoller, TDelivery, TEnvelopeReader >

Accepts and reads the inbound connections of an actor system on an I/O thread.

The accept loop and one coroutine per connection run on poller, which belongs to another thread (see TLoopThread). A connection reads its socket into its own TEnvelopeReader, as a connection of TActorSystem::Serve(TSocket) does, and hands the envelopes of every read to delivery in one TEnvelopeBatch. Envelopes for another node are dropped and logged, as there.

TDelivery is the way to the actors; TQueuedDelivery is the one for an actor system on another thread. Both calls are made on the I/O thread:

  • bool Full() const — while it is true, the connections do not read: the bytes stay in the sockets, and TCP slows the senders down. A connection asks before each read, so each one hands over at most one read beyond the limit of the delivery.
  • void Deliver(std::unique_ptr<TEnvelopeBatch> batch).

A finished connection closes its socket; the inbound forgets it at the next accept.

TLoop<TDefaultPoller> loop; // the loop of the actor system
TLoopThread<TDefaultPoller> io; // before sys: it outlives the nodes on io
TActorSystem sys(&loop.Poller(), 1);
sys.AddNode(2, ...); // a TNode on loop or a TThreadedNode on io
TQueuedDelivery delivery(sys);
TAddress address{"::", 9001};
TDefaultPoller::TSocket listener(io.Poller(), address.Domain());
listener.Bind(address);
listener.Listen();
TThreadedInbound<TDefaultPoller, TQueuedDelivery, TZeroCopyEnvelopeReaderV2> inbound(
io.Poller(), std::move(listener), 1, delivery);
sys.ServeOutbound();
io.Start();
...
io.Stop();
io.Join();
// inbound, delivery and sys with its nodes are destroyed here, then io and loop

Template Parameters
TPollerPoller type of the I/O thread; determines the socket type.
TDeliveryReceives the batches, see above.
TEnvelopeReaderTZeroCopyEnvelopeReader, which copies every payload into an allocation of its own, or TZeroCopyEnvelopeReaderV2, whose payloads point into its chunks and may be released on any thread.
Note
Construct it before the loop of poller starts and destroy it after that loop has stopped: both touch the poller. listener is a listening socket on poller.
The logger is called on the I/O thread.
Not available on Windows: I/O threads need TNotifier.
