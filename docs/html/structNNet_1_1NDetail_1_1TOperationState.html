Detailed Description

State of one operation of a completion-based poller (TUring, TIOCp).

It lives in the operation's awaitable, inside the waiting coroutine's frame. The poller refers to it from posting until the completion is delivered or Cancel() returns, and the awaitable cancels the operation in its destructor, so it outlives every reference. Index lets Cancel() find it in O(1). The poller and the system keep its address, so it can be neither copied nor moved.
