Detailed Description

Thread-safe notification with a single asynchronous listener.

Producers call Notify() from any thread after publishing work. Calls coalesce until Wait() consumes the signal; a notification means "check for work", not one work item. Wait() re-arms the notifier before returning to the listener.

TNotifier notifier(poller);
// Producer thread: publish work, then signal the listener.
notifier.Notify();
// Event-loop coroutine: wait, then drain available work.
co_await notifier.Wait();

Note
Linux uses eventfd; other POSIX platforms use a non-blocking pipe. Supports readiness pollers: epoll, kqueue, poll, and select.
The poller must outlive the notifier. Stop producers and destroy or complete all waits before destroying the notifier.

TFuture< void > NNet::TNotifier::Wait ( )

Asynchronously waits for and consumes a notification.

Call on the poller thread, with at most one outstanding wait. The caller must check all available work after waking because notifications coalesce. Destroying an unfinished future cancels its wait on the poller thread.

Exceptions
std::logic_errorif another wait is already outstanding.
