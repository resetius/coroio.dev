Detailed Description

Byte buffer of the outbound stream of TNode: grows without zero-filling.

std::vector<char>::resize writes zeros into every byte it adds, and the writers overwrite them right away. This buffer only owns memory: Reserve makes room, the caller tracks how many bytes are in use and writes every byte before it reads it. The memory is not initialized, so a serializer must not leave gaps in the range it was given.

It grows geometrically and never shrinks. A block that is mostly full is grown by realloc, which lets the allocator extend or remap it, and copies the whole old block only when it cannot (at most twice the bytes in use). A block that holds mostly stale bytes is replaced by a new one and only the bytes in use are copied.
