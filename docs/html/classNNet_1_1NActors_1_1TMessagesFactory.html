Detailed Description

Serializers and deserializers of message types, by message id.

  • RegisterSerializer<T> lets a node write T to the wire.
  • RegisterPayloadWriter<T> also lets a TThreadedNode write the payloads of Near objects of T on its I/O thread; the I/O thread does not read the factory for it.
  • RegisterDeserializer<T> lets a TThreadedInbound build T on its I/O thread.

Registration and the lookups of the nodes run on the thread of the actor system. Register the deserializers before the inbound threads start: they read the factory.

◆ RegisterPayloadWriter()

template<typename T>
void NNet::NActors::TMessagesFactory::RegisterPayloadWriter ( )
inline

RegisterSerializer<T>, and a TThreadedNode writes the payloads of Near objects of T on its I/O thread.

The node takes SerializedSize in Send and calls SerializeTo later, on its I/O thread, where it then destroys the object. So for T:

  • what SerializeTo reads must not change, and must stay alive, until the object is destroyed;
  • the destructor of the object and the deleter of its blob must be safe on the I/O thread;
  • SerializeTo must not throw: check the object in SerializedSize, which throws to the sender. An exception from SerializeTo terminates the process.
