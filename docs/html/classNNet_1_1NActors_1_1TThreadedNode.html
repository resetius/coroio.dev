Detailed Description

template<typename TPoller, typename TLock = TNullLock>
class NNet::NActors::TThreadedNode< TPoller, TLock >

INode that writes to its socket on another thread.

The node has two sides:

  • Producer side — the thread of the actor system. Send, Acquire, Commit and Offset put frames into a segment in memory, exactly as TNode puts them into its buffer. Drain hands the segment to the I/O side and takes an empty one.
  • I/O side — a coroutine on poller, which belongs to another thread (see TLoopThread). It connects, writes the segments to the socket in the order of Drain calls and returns them for reuse. At most MaxSpareSegments written segments are kept, each with the memory of its buffer; the rest are deleted.

The byte stream is the one TNode writes: reconnects with a 1 s back-off, a failed write drops the segment being written, and a reconnected stream starts with a filler frame once a frame with PayloadAlignment has been written (see WriteFiller). Unlike TNode, committed bytes are not sent until the next Drain.

Send defers the serialization of a Near object of a type registered with TMessagesFactory::RegisterPayloadWriter, which states what such a type must allow. The producer side takes the size of its payload and frames it, so the frame keeps its place among the frames written around it and the stream stays that of TNode. The I/O side writes the payload into the frame with SerializeTo before the segment goes to the socket, and destroys the object there; it does not read the factory. All other payloads are serialized in Send, as by TNode.

TLock guards the producer side. With the default TNullLock it has one producer thread. With a real lock (std::mutex) any thread may produce: Send, StartConnect and Drain take the lock themselves, and a caller of Offset, Acquire and Commit holds ProducerLock() across the three calls that write one frame.

inlineoverridevirtual

Stream offset of the next Acquire, or a value congruent to it mod MaxPayloadAlignment: payloads with PayloadAlignment are padded relative to it, and only their writers call it. The default suits a stream that keeps each frame in its own buffer.
