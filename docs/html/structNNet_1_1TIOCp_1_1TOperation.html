Detailed Description

State of one operation, kept by the caller.

Set TOperation::Handle to the coroutine to resume before posting the operation; if posting throws, it is reset. The state is the operation's OVERLAPPED, so it must stay in place until WakeupReadyHandles() delivers the completion or Cancel() returns. The result of the completion is in TOperation::Result.
