Detailed Description

template<typename T>
class NNet::NDetail::TIntrusiveNode< T >

Links of an object in a TIntrusiveList.

Derive the object from it: struct TItem: TIntrusiveNode<TItem> { ... };. The object is in at most one list at a time, and the list does not own it.
